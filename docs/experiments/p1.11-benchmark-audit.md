## Spot-check packet (for G1)

The 20 worlds are seeded (20261012) and stratified, each spanning tiers
round-robin:
- 6 CedarBench;
- 4 Quacky;
- 5 synthetic repo;
- 5 synthetic MCP.

`scripts/authinv_spotcheck.py` generates the packet. It shows each world's
facts, all six renderings, and two sample requests with certified labels.
It contains no model output.

```sh
uv run --extra engines python scripts/authinv_spotcheck.py \
  --benchmark outputs/20261008T112623005337Z_authinv_benchmark --out spotcheck.json
```

Review form, shared with Jerzy as a private claude.ai page:
https://claude.ai/artifact/AVWsW49ERwGqvNtPiZKCrJ. Each saved verdict is a
record in its `reviews` collection:
- clear / ambiguous;
- which renderings are ambiguous;
- a note;
- world id and policy hash.

G1 passes if no rendering reads as ambiguous. If a world is flagged, the fix
becomes a new, versioned step: a renderer change means a rebuild.

# Synthetic policy sources (P1.6)
- status: done
- result: data audit (not a model experiment): **720 / 720 generated worlds certified** across all five renderings

## What

Grammar-generated authorization worlds in two domains:
- **repo**: GitHub-style. Users with level/team, teams as groups, repos with
  team/visibility; actions read/push/merge/delete; context mfa/hour.
- **mcp**: MCP tool allowlists. Agents with clearance/env, roles as groups,
  tools with category/risk; actions call/configure/list; context approved.

Worlds come from a 24-cell design grid per domain:
- tier single / multi_rule / conditioned;
- roles 1–3, the number of permit rules, each granted to a different group;
- 0–3 conditions;
- effect pattern permit_only / with_forbid.

Each cell has 15 replicates. Identifiers are neutral codes. Each world has 5
principals, 3 groups, and 3 resources. Spec: `src/authinv/sources/synthetic.py`;
config: `configs/authinv/synthetic.yaml` (seed 20261009).

```sh
uv run --extra engines python scripts/authinv_build_synthetic.py --config configs/authinv/synthetic.yaml
```

Output: `20261008T074323394554Z_authinv_synthetic` (git-ignored; equivalence.jsonl sha256 `1db4652af730f5d3…`).

## Acceptance rules

A world is accepted only if it is non-degenerate:
- its request universe has ≥ 4 allow and ≥ 4 deny requests, with ≥ 2
  boundary requests for each label;
- every rule changes at least one decision (no dead rules).

It must then pass P1.4 certification: all five renderings decode, match the
reference decisions on the whole universe, and the Cedar engine agrees and
typechecks.

**Balance of kept worlds.** The design factors are exactly balanced:
- domain: 360 / 360;
- roles: 240 each;
- conditions 0/1/2/3: 180 each;
- effect: 360 / 360.

Tiers follow the grid's cell counts: single 30, multi_rule 150, conditioned
540. P1.10 can rebalance tiers when it samples the benchmark.

**Universe sizes.** Each universe has 45–720 requests (median 60). The allow
share runs 1.1%–68.9% (median 15.6%). P1.10 samples balanced allow/deny,
boundary requests first (`authinv.equivalence.requests.sample_requests`).

## Conclusion

The synthetic sources provide 720 engine-certified worlds, balanced over
effect, role count, and condition count. Together with CedarBench (P1.7),
Quacky (P1.8), and ACRE (P1.9), they feed the ≥ 1,000-world benchmark built
in P1.10.

Rejections come mostly from the "too few allow" rule, and they're frequent
in the MCP domain. That domain's conditions are restrictive (e.g. clearance
≥ risk), and the retries are recorded rather than hidden.
